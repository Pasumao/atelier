## 1. 定位与总目标

**定位一句话**（原 `TECH-ASSESSMENT.md` 定位声明；2026-09 三路调研复核仍成立）：Atelier 不参与"更快渲染"的主流竞赛；它下注"当编码代理成为前端第一类使用者，框架应内建契约、检视、恢复与结构公理"。

**12 个月总目标**：把经扫描确认仍无人区的四项能力做深（扁平 schema 三用 / 事务层双轨回滚 / 六层结构机检 / 可执行意图规格），用极低成本完成与开放标准的对齐拿到 40+ 客户端分发通道，用受控实验回答"技能包价值"与 Vercel 反证——最终以 v0.x 形态对外发布。

**北极星指标**（可证伪，详见 §7）：加难任务层上的 agent 首遍正确率（≥ +15pt 或绝对值 ≥ 60%）。

## 3. 三条主轴

1. **壮大框架本体**（F 线兑现）——编译期静态化是决策 3 的未兑现承诺，也是性能与 prod 剥离的地基；用户已定论这是主菜。
2. **深挖 agent 纵深**——在主流框架只做到"暴露运行时状态"的地方，做到"契约联动、依赖图可查、双轨可逆"；四无人区是差异化的最后阵地。
3. **标准对齐与受控验证**——标准符合性=分发通道（低成本高回报）；M3 加难实验同时回答"技能包价值"与"Vercel 反证"两个问题。
