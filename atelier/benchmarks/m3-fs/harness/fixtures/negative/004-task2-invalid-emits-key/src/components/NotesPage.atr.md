# NotesPage — 意图验收单（task2：live 订阅 + §4.5 乐观对账）

## 意图

笔记列表页：live 订阅服务端 notes 列表（写后失效-重算-推送），用户提交新笔记采用
§4.5 乐观对账五步协议（待定先行 → 提交 → commit/revert → live 帧对账服务端胜出）。

## 验收（行为化）

1. 打开页面即建立 SSE 订阅，首连收到全量列表并渲染（每行带 `data-note-id`）；
2. 提交新笔记：该笔记**立即**以待定态出现在列表（`data-pending="true"` + pending 徽标）；
3. 提交成功：待定转已确认；live 推送到达后该行以服务端值为准存在且**仅一次**（无重复行）；
4. 提交失败（如空 body 被 ATR-201 拒绝）：待定行消失、回滚名单（`data-rollbacked` 元素）
   含该 id、错误卡展示 code/message/fix；
5. 失败路径与成功路径都不弄脏列表其余部分；live 重算失败（ATR-321）不断流不白屏。

## 边界

- live 推送是真相源，optimistic 状态只是先行渲染（同 id 服务端值胜出）；
- 行样式全走 token 工具类（决策 16），不引入新颜色。
